Autolith, or AL, is a small terminal agent that runs inside a Common Lisp
image. It owns its model loop, tools, conversations, authentication, live
mutation, checkpoints, and recovery. It talks directly to the ChatGPT Codex
and Grok subscription services and does not launch or bundle the Codex CLI
or Grok Build.

Autolith supports Linux x86-64 and native macOS arm64 source checkouts on
SBCL. Nix and binary releases remain Linux x86-64. Autolith is dogfoodable,
but it is not a security sandbox: model-generated Lisp runs with the user's
privileges, and the user can grant commands full access for a session.

* Highlights

- A responsive primary-screen terminal interface with ordinary scrollback.
- Multiline editing and reusable completion widgets from Clinedi, with shared
  terminal styling from cl-colorist.
- Input remains editable while model responses and tools are running.
- Local PNG, JPEG, GIF, and WebP input with numbered composer labels.
- Persistent, opt-in provider-visible reasoning summaries with =/trace on=.
- Append-only portable conversation files with exact resume commands.
- Optional root =AUTOLITH.org= notes for documented project adaptations.
- Native Skills with explicit, request-local instruction loading.
- MCP 2025-11-25 and 2025-06-18 over standard I/O or Streamable HTTP,
  including tools, resources, and prompts.
- Workspace and global persistent memories with ranked request-local recall.
- Short workspace agendas with memory links and repository transport.
- Warm in-process fff path, glob, plain, regex, fuzzy, and multi-pattern search.
- Everyday filesystem and shell tools plus named, isolated Lisp REPLs.
- Immutable modified worker images with notes and pristine side-by-side comparison.
- Hash-verified matching SBCL source and Lisp-level implementation instrumentation.
- Live =self.*= mutation with private commits and complete replay scripts.
- Optional =--immutable= startup with inspection-only =self.*= tools.
- Forked checkpoints with per-generation reconstruction artifacts.
- A validated preloaded active image for fast startup and source fallback.

* Install and start

On Linux x86-64, Nix is the recommended installation path. It pins the
complete runtime and keeps it separate from the host system.

#+BEGIN_SRC sh
nix run github:luciusmagn/autolith
#+END_SRC

The conventional Linux x86-64 installer is shorter, but piping network input
into a shell deserves suspicion. Inspect [[https://sh.lambda-symbolics.com/autolith][the script]] first if you use it.

#+BEGIN_SRC sh
curl -fsSL https://sh.lambda-symbolics.com/autolith | sh
#+END_SRC

The binary release contains its own pinned SBCL, matching SBCL source, locked
Lisp dependencies, search library, and private sandbox helper. It needs Git,
OpenSSL, and Bubblewrap from the host. The first launch builds machine-specific
recovery and active images without requiring Quicklisp, a compiler, or a source
checkout. Autolith checks published releases periodically and asks before
installing a newer release. The check runs in the background and never installs
anything unattended. A prior cached result may place an update notice below the
next startup banner. Run =autolith --update= to check and update explicitly.

Native macOS arm64 currently runs from a source checkout. Autolith accepts any
SBCL at least the version in =sbcl.version= (currently 2.6.4). Install the
host toolchain and Quicklisp, then let bootstrap install the matching SBCL
source, native libraries, recovery core, and active core:

#+BEGIN_SRC sh
brew install sbcl rust cmake pkg-config openssl@3
curl -o /tmp/quicklisp.lisp https://beta.quicklisp.org/quicklisp.lisp
sbcl --no-sysinit --no-userinit --load /tmp/quicklisp.lisp \
  --eval '(quicklisp-quickstart:install)' --quit
./script/bootstrap
./script/check
./bin/autolith
#+END_SRC

The macOS command sandbox uses the system Seatbelt launcher. See
[[file:docs/guide.org][the guide]] for the platform boundary and source setup details.

Authenticate and start a conversation:

#+BEGIN_SRC sh
autolith --auth
autolith
#+END_SRC

=autolith --auth= signs into the provider serving the configured model, and
=autolith --auth grok= or =autolith --auth chatgpt= selects one explicitly.
Inside a session, =/model= switches between the GPT and Grok model families
and =/auth= authenticates the active provider.

If a development checkout has no current fast startup image, the launcher asks
whether to run its bootstrap. Use =autolith --from-source= to deliberately load
the checkout without validating or rebuilding that image.

Enter submits. Shift-Enter, Ctrl-Enter, or Alt-Enter inserts a newline. While
idle, Ctrl-C clears a draft or exits an empty prompt without confirmation.
During an active turn, Escape or Ctrl-C cancels only that turn without clearing
the draft or queued messages and returns to the prompt. Only active Ctrl-C opens
a 2.5-second force-exit window while cancellation is pending; pressing Ctrl-C
again in that window forces exit and prints the resume command. A turn that
cancels promptly never announces that window. Escape never forces exit. Up and
Down move across visual
input rows before falling back to history. Tab and Shift-Tab cycle command
suggestions. Messages can be drafted and queued while AL is responding. Type
=/help= for commands.

* Persistent paths

Autolith keeps user-authored Lisp, native MCP configuration, user Skills, and
child-agent definitions under =${XDG_CONFIG_HOME:-~/.config}/autolith/=.
Project Skills live below the project root's =.autolith/skills/=, and Autolith
may provide lower-precedence bundled Skills. Credentials, preferences, exact
command approvals, deferred inputs, live-mutation journals, and atomic
selections belong under =${XDG_STATE_HOME:-~/.local/state}/autolith/=, together
with the readable cached release availability and a private Git history of
durable mutation snapshots. Conversations, canonical
image commits, memories, generations, runtimes, matching implementation source,
and worker images live under =${XDG_DATA_HOME:-~/.local/share}/autolith/=. Credentials
never belong in Git, conversation files, memories, journals, manifests, or
saved cores.

Source remains authoritative for clean rebuilds. Saved cores retain exact live
states; private image commits and each generation's =reconstruct.lisp= retain
durable user-specific changes without patching the tracked repository. Missing
canonical replay artifacts are restored from the separate private Git history.

* Development

Source development additionally needs Quicklisp, Rust with Cargo, a C compiler,
CMake, =pkg-config=, and a host SBCL when the pinned runtime must be built from
source. Materialize the locked environment and baseline images with
=./script/bootstrap=.

Run the complete check after every change:

#+BEGIN_SRC sh
./script/check
#+END_SRC

Refresh dependencies and both installed baseline images with
=./script/bootstrap=. Rebuild only the pristine recovery image with
=./script/build-recovery=. See [[file:AGENTS.md][AGENTS.md]] before editing and the
[[file:docs/autolith-minimal-technical-spec.org][technical specification]] before changing architecture.
