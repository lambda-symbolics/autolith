Autolith, or AL, is an agent inside a live [[https://en.wikipedia.org/wiki/Common_Lisp][Common Lisp]] image:

- *Live self-modification:* Inspect, modify, and extend its own code and running state,
  with checkpointing and recovery mechanisms to survive failed modifications.
- *Symbolic reasoning and memory:* Retain knowledge, derive facts, and minimize
  unnecessary LLM involvement through persistent memory, symbolic inference, and compaction.
- *Large-scale data processing:* Use [[https://arxiv.org/abs/2512.24601][Recursive Language Models (RLM)]] to process
  enormous amounts of information without flooding its context window.
- *Multi-agent coordination:* Coordinate self-organizing councils and hierarchies
  of persistent agents through a /World of Channels/, with different models, reasoning efforts, and roles.
- *Long-horizon autonomy:* Pursue goals autonomously, with explicit verification
  criteria, scheduled continuations, and persistent plans.
- *Extensibility:* Extend its capabilities through tools, skills, [[https://modelcontextprotocol.io/][MCP]] servers, and direct integration with editors and other software.

This lets Autolith adapt to the user's preferences and the demands of the task,
making it particularly suited for long-horizon work. Channels should be reused
across tasks, retaining their accumulated context and state.

Autolith emphasizes good ergonomics, good visuals, full [[https://en.wikipedia.org/wiki/Freedesktop.org][XDG standard]]
compliance, and minimal intrusiveness.

Its architecture is somewhere between [[https://www.gnu.org/software/emacs/][Emacs]] and a [[https://en.wikipedia.org/wiki/Lisp_machine][Lisp Machine]]. Autolith is
a full kitchen-sink Common Lisp runtime, and there is no difference between
Lisp evaluation, tool calls, and commands. Your prompt input is a [[https://en.wikipedia.org/wiki/Read%E2%80%93eval%E2%80%93print_loop][REPL]] with
syntactic sugar. *You don't need to know Lisp.*

Autolith supports the following platforms
- Linux (x86_64 + aarch64)
- MacOS (x86_64 + aarch64)
- FreeBSD (x86_64)
- NetBSD (x86_64)
- OpenBSD (x86_64)
- Windows (x86_64)

* Install

Standalone binary releases are available for Linux, MacOS, the BSDs and Windows.
Nix packages are also available and, for many, preferred.

On Linux, MacOS and the BSDs, the curl-into-sh installer installs or updates the
packaged release for your platform. Inspect the
[[https://sh.lambda-symbolics.com/autolith][installer script]] before piping it into a shell, or trust us with your life,
hehe.

Good systems:
#+BEGIN_SRC sh
curl -fsSL https://sh.lambda-symbolics.com/autolith | sh
#+END_SRC


Windows:
#+BEGIN_SRC sh
irm https://sh.lambda-symbolics.com/autolith | iex
#+END_SRC

Best systems:

#+BEGIN_SRC sh
nix run github:lambda-symbolics/autolith
#+END_SRC

To build from a source checkout instead, follow the
[[file:docs/guide.org][guide]]'s Source checkout section.

Authenticate providers:

#+BEGIN_SRC sh
autolith auth chatgpt
autolith auth copilot
autolith auth gemini
autolith auth grok
autolith auth nous
autolith auth anthropic
autolith auth fireworks
autolith auth opencode
autolith auth openrouter
autolith auth mistral
autolith auth vertex-gemini
autolith auth vertex-anthropic
#+END_SRC

For Vertex AI, first run =gcloud auth application-default login= and set
=GOOGLE_CLOUD_PROJECT= to your project ID. See the [[file:docs/guide.org][guide]] for setup details.

Then start Autolith:

#+BEGIN_SRC sh
autolith
#+END_SRC

* Update
If you want to pull an update, you can do so easily:

#+BEGIN_SRC lisp
(update)
#+END_SRC

Or do *autolith update* in your shell.
