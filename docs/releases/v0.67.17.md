# Autolith 0.67.17

## Improvements

- Bound resident fullscreen scrollback, editable input history, and cached action traces. Recall older output and inputs from durable logs.
- View heap usage, resident transcript and trace sizes, input recall counts, and knowledge counts in `/status` alongside request spending.
- Stream input-history publication and recall instead of retaining complete histories in memory.

## Fixes

- Traverse input history in both directions across count and character limits, including newly appended inputs. Restore the draft and cursor after recall.
- Charge complete procedure provenance against trace budgets and release oversized traces.
- Report when a retired inference environment's bindings are no longer available.
