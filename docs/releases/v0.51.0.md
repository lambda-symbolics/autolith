# Autolith 0.51.0

## Configuration

- Every knob is now a named setting with a type, description, default, options, and scope. Read one with `(config :model)` and change one with `(setf (config :reasoning-traces-p) t)`.
- `(settings)` opens a settings page listing each setting with its value and source; adjustable settings change in place. `(settings :onboarding-p nil)` and `(settings :boot-screen-seconds 2)` change values, while `(settings :terminal-theme)` inspects one setting.
- The former `configuration-<name>` readers, `configuration-with-<name>` copiers, and `preferences-<name>` functions still work in 0.51, warn on every call from 0.52, and are deleted in 0.54. A test in the check suite fails from 0.54 until they are gone.
- Test workers now run with their own config and state roots, so the check suite never reads or rewrites the developer's preferences.

## Codex

- Codex requests reuse one pooled connection instead of opening a new TLS connection per request. The ChatGPT backend keeps the prompt cache per backend, and a fresh connection landed on a different backend often enough that the cached prefix stopped growing between tool rounds. The Codex CLI advanced its cache on 96 percent of tool rounds; Autolith advanced on 20 to 55 percent.
- The `x-codex-turn-state` routing token is pinned for the whole turn instead of replaced by each response, and Codex requests carry the conversation identifier in the `session-id`, `thread-id`, and `x-client-request-id` headers, as the Codex CLI does.
- Task children use a prompt cache key derived from their root instead of the root's own key, so parallel children no longer route onto the root's cache.
- An HTTP 429 whose body reports `usage_limit_reached`, `usage_not_included`, or an exhausted quota fails immediately with the plan and reset time instead of running the retry ladder.
- `(cache-misses t)` also reports a stalled cache, where reads stop growing behind a growing prompt, and says whether the instructions and tools were re-read or still cached.

Update with `(update)`.
