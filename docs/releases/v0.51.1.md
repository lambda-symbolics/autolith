# Autolith 0.51.1

## Headless jobs

- Resolve a `run-job` role after loading the application's user initialization. User roles can now select models registered by `register-openai-compatible-provider` in `init.lisp` ([#76](https://github.com/lambda-symbolics/autolith/issues/76)).

## Settings and interface

- Use the active or initialized configuration as the default for `(config ...)`.
- Show explicit setting sources and correct the settings tip; search within the settings option picker.
- Keep fullscreen selection session-only and pluralize picker match counts.
- Declare configuration persistence hooks before their use.

Update with `(update)`.
