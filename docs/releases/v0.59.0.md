# Autolith 0.59.0

## GitHub Copilot

- Add GitHub Copilot subscription support through `autolith auth copilot` or `(auth "copilot")`, contributed by Elmo Todurov ([#85](https://github.com/lambda-symbolics/autolith/pull/85)).
- Discover account-accessible tool-capable models under `copilot/<model-id>`, select a Copilot model after login, and renew tokens automatically.
- Support Chat Completions, Responses, and Anthropic Messages, including tools and image input. For Enterprise Cloud data residency, configure `AUTOLITH_COPILOT_DOMAIN=TENANT.ghe.com`.
- Share Copilot catalog decoding, endpoint validation, and wire headers through `cl-llm-provider-api`. Recover invalid route caches through explicit authentication.

## Providers and terminal

- Preserve signed and redacted Anthropic thinking across saved-conversation reloads and follow-up requests.
- Decode keyboard input consistently in fullscreen and inline terminal modes ([#84](https://github.com/lambda-symbolics/autolith/issues/84)).
- Make Ctrl-U delete text before the cursor while preserving text after it.

Update with `(update)`.
