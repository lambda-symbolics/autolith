# Autolith 0.16.3

Autolith 0.16.3 makes session goals editable in place and stops busy slash
commands from bouncing back to the editor.

## Goal editing

- Added `/goal update NEW-OBJECTIVE`, which rewrites the current objective in
  place while preserving the goal's creation time.
- Kept a paused goal paused across an update and restarted the continuation
  budget for the revised objective.
- Reactivated a completed goal when its objective is updated.
- Rejected empty and command-shaped update objectives with usage guidance
  instead of corrupting the goal.

## Responsive command scheduling

- Scheduled slash commands submitted during an active turn as follow-up work
  that runs at the first idle opportunity instead of returning them to the
  editor for manual resubmission.
- Previewed scheduled commands in the live region alongside queued messages;
  Tab with an empty draft still recalls the newest one for editing.
- Kept argument-free inspection commands executing immediately and kept
  Ctrl-C turn cancellation unchanged.
