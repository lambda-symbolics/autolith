# Autolith 0.41.2

Autolith 0.41.2 fixes safely confined skill discovery and slash-command argument handling.

- Follows symlinked skill directories when their canonical targets remain beneath any configured discovery root.
- Rechecks the configured-root confinement policy when selected skill instructions are read again.
- Handles literal filesystem names such as unmatched brackets without aborting discovery of neighboring skills.
- Preserves multiword objective input as one free-form argument for `(goal "OBJECTIVE")` and the historical deferred scheduler.
- Reports excess command arguments through guarded command execution instead of entering the debugger.
