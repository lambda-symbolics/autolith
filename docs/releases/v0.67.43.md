# 0.67.43

## Channel deletion

- Use `(delete)` for the invoking client's current channel, or `(delete "ID")` for a unique channel-ID prefix.
- Confirm removal of the channel, its nested channels and their history. When deleting the displayed channel or an ancestor, switch the invoking terminal to the inbox before removal.
- Reuse the durable removal checks for active work, attached clients and conversation leases.

## Sidebar

- Use fixed `(new)` and `(delete)` buttons below the channel tree.
- Scroll the drawer with the mouse wheel or PageUp/PageDown; use the heading arrows in the docked sidebar.
- Keep selection and click targets aligned while scrolling, resizing and refreshing the tree.

## Response display

- Coordinate live streaming and transcript replay so replies appear once, including responses with several message or text parts.
- Release the stream display state after interrupted requests so later messages can render normally.

## Context accounting

- Carry measured context usage across restart when the retained history and model match. Estimate changes to the prompt or tools separately from encrypted reasoning data.
- Mark usage as estimated when the prompt, tools or unmeasured history change.
- Retain the measured ordinary context when compaction returns no usable result; invalidate it when replacement history is published.

## Child agents

- Allow three levels of child-agent delegation by default.

Update with `(update)`.
