# Autolith 0.27.0

Autolith 0.27.0 makes long-running work inspectable, preserves queued input through crashes, and surfaces child-agent activity as it happens.

- Run top-level `task.run` calls detached by default, with `blocking: true` for synchronous child work and consistent policy inheritance across batches.
- Unify child and asynchronous execution lifecycle under inspectable session jobs. Shell and selected Lisp calls return normally when they finish within ten seconds or hand off the same exactly-once job without re-execution.
- Cascade cancellation through task descendants, clean interrupted Lisp worker streams, and retain bounded terminal job summaries.
- Show bounded cumulative child activity traces with live tool elapsed time, compact detached rows, and viewport-aware expanded rows for blocking work.
- Preserve dispatched work, steering, follow-ups, and commands after active Ctrl-C or an active-image crash without submitting recovered input automatically.
- Add conversation-scoped `(vault)`, `(vault-restore)`, and `(vault-discard)` controls with transactional ordering, idempotent imports, and corruption-safe storage behavior.
- Restore syntax-highlighted source and change rendering with green source and added rulers, red removed rulers, dim context, and bounded omission rows.
- Display a bright animated `COMPACTING` row above the modeline while conversation compaction is active.
- Make model and reasoning-effort pickers searchable, and distinguish literal Ctrl-D from physical terminal EOF throughout interactive readers.
- Update the pinned clifff integration to fff v0.10.3 across bootstrap, runtime, and Nix builds.
