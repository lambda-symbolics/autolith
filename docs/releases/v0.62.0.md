# Autolith 0.62.0

## Emacs and sly

- Develop in Autolith's active Lisp image through sly. Load `emacs/autolith.el` and run `M-x autolith-ide` for code, a sly REPL, and an agent-shell conversation in one frame.
- Start just the conversation with `M-x autolith-agent-shell`. Autolith can show file positions with `emacs.visit` and evaluate authorized Emacs Lisp with `emacs.eval`.
- Read visible windows, the active region, and open file buffers through `emacs:current`. Read and edit unsaved buffer text through `emacs:buffer/NAME`, with revision checks and Emacs undo history. Outside-workspace buffers require authorization.
- Configure Slynk from your own sly installation with `AUTOLITH_SLYNK_DIRECTORY` and `AUTOLITH_SLYNK_PORT_FILE`. Slynk listens on loopback, starts in the background, and closes before shutdown or checkpointing. Reconnect after a checkpoint with `M-x autolith-ide-reconnect`.
- Tell the agent when sly shares its image, and compose resource tool descriptions from the schemes available in the session.

Update with `(update)`.
