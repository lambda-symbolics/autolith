# Autolith 0.70.0

## Lisp procedures

- Define reusable Lisp functions with `procedure.define` and run them with `procedure.run`.
- Call tools as functions in the active image and in procedure bodies.
- Inspect stored procedures with `(procedures)` or `memory:procedures`.
- Redefine existing learned procedures as Lisp procedures.

## Packaged product names

- Set `AUTOLITH_DIRECTORY_NAME` to choose the name of the per-user directories.
- Set `AUTOLITH_PRODUCT_NAME` to choose the displayed product name.
- Set `AUTOLITH_COMMAND_NAME` to choose the command name in help and suggested commands.

Nix packagers can supply defaults through `nix/package.nix`. Use `siteConfigRoot` to select a site configuration directory. Nonempty environment variables override the packaged defaults.
