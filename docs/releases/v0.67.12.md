# Autolith 0.67.12

## Features

- Inspect current work with `(btw)` or `(side)` while a turn is running. View colored status in the ledger, revisit it with Ctrl-PgUp/PgDn, and replay it from history. Status records are excluded from model context.

## Fixes

- Report the owner of a conversation lease when startup encounters a locked conversation.
- Observe session exit after `lg kill` and return a failure status when the process is still running or its exit cannot be confirmed.
- Show stalled job cancellations and retain completion evidence until cancellation finishes.

Update with `(update)`.
