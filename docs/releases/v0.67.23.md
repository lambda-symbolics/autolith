# Autolith 0.67.23

## Improvements

- See completed background-job results while a mission is paused, blocked, or out of budget, without starting another provider turn. See why automatic continuation stopped.
- Choose `:unknown-usage-policy :record` to record missing provider usage and continue a mission under its other limits. The default policy is `:block`.
- Keep mission schedules through pauses and blocks, and resume eligible schedules with the mission.

## Fixes

- Retry transient service-unavailable, overload, and rate-limit provider events with bounded backoff. Show the attempt count and error code when retries are exhausted.
- Keep served tool output stable when only a cache-retention estimate expires, including same-provider resumes without a declared cache lifetime.
- Defer completion-driven turns while other work reserves the remaining tokens, then reconsider them after settlement. Explain blocked continuations according to the mission's usage policy and current state.
