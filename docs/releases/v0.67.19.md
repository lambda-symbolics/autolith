# Autolith 0.67.19

## Improvements

- Start a session without attaching with `autolith --detached`, or resume one with `autolith resume PREFIX --detached`. Read the conversation ID and running session PID from the output.
- Resume conversations by an unambiguous ID prefix. When several match, inspect every matching conversation's full ID and context before choosing.
- Index unfinished jobs for faster completion checks and release finished child completion services.
- Bound command-permission caches and knowledge views per workspace.
- Forget context state for finished children and inference frames.

## Fixes

- Bound shell-output delivery checks and preserve exact positive evidence across compaction, reload and conversation retention. Backfill older delivery evidence incrementally. Keep undelivered captures regardless of age.
- Prune shell logs with interrupts enabled and store pending-input receipts in a set instead of repeating linear scans.
- Use Lisp command notation in cost documentation and published release notes.

Update with `(update)`.
