# Autolith 0.23.3

Autolith 0.23.3 adds durable, user-visible papercut reports.

- Add the model-facing `papercut.report` tool for concrete Autolith limitations,
  broken tools, repeated friction, and blockers.
- Store bounded reports in an append-only readable log outside conversations and
  saved cores, partitioned by workspace and tied to the source conversation.
- Keep successful reports prominent even in compact tool presentation.
- Add `(papercuts)` to list workspace reports and `(papercut "ID")` to show one
  complete report with exact or unique-prefix identifier resolution.
- Document the persistence, presentation, prompt, command, and failure behavior.
