# 0.67.38

## Fullscreen

Drag a text selection beyond the transcript's top or bottom edge to scroll while selecting.

Show the boot screen before opening a saved channel, then transition directly to its restored transcript.

## Channels

The channel command is now `(open)`, renamed from `(switch)`. Use `(open)` to pick a channel or `(open "ID")` to open one directly. Startup selection, sidebar actions, clickable channel links, completion and help use the new name.
