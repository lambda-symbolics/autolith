# 0.67.34

## Cancellation

- Cancel child jobs with their parallel tool executions. Pending calls are no longer admitted after cancellation, and active executions use cl-jobpond supervision.
- Cancel blocked nested mission executions across inline jobs and separate pools, with stale-run protection.
- Interrupt worktree setup without losing checkout ownership. Cancelled-task edits are retained with a pending artifact for later extraction.
- Notify running descendants before publishing queued cancellation results across both pools. Terminal publication no longer includes retention sweeps.
- Bound native termination and reaping. Unfinished process and capture-reader ownership is reported and retained until cleanup completes.

Update with `(update)`.
