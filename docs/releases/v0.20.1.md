# Autolith 0.20.1

Autolith 0.20.1 is a hotfix for session goals and release-host checks.

## Session goals

- Setting or actively updating a session goal now starts a model turn immediately,
  so `(goal "OBJECTIVE")` no longer waits for a separate user message.

## Release and test reliability

- Conversation lease tests use a fresh SBCL process when the suite already has
  multiple threads, so `./script/check` no longer dies with
  `Cannot fork with multiple threads running` on the release host.
