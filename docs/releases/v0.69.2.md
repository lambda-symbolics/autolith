# Autolith 0.69.2

## Shell commands

- Fix slow shell startup when many capture logs are retained (#277). Storage is accounted incrementally, and retention runs in bounded background batches.
- Reconcile capture storage after process restarts and interrupted accounting updates before reserving new space.

## Providers

- Fix inflated Codex context estimates for images returned by tools (#275). Image data receives the image allowance instead of being counted as encoded text.

## NetBSD

- Use indexed package downloads, validate the cached packages before installation, and try another mirror after a transfer failure.

Update with `(update)`.
