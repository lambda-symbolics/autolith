# Autolith 0.22.0

Autolith 0.22.0 improves child-agent context, urgent execution, terminal input,
provider recovery, and session reliability.

## Child-agent context

- Child agents inherit a bounded, filtered snapshot of portable parent history
  behind an explicit developer boundary.
- Root conversations and their children share prompt-cache lineage while
  unrelated conversations remain isolated.
- Parent references are captured atomically, persisted in private child
  transcripts, bounded to 32 KiB, and removed from retained terminal job state.
- Conversation compaction, malformed inherited records, and detached task
  publication received additional race and failure handling.

This work integrates Jack Chakany's `subagent-fork-context` contribution with
additional isolation, boundedness, and recovery fixes.

## Faster focused execution

- Added `(hurry-up)`, a session-only direct-execution profile with transient
  urgency notices and a hard two-child admission limit.
- `(model)` and `(effort)` changes submitted during an active turn now wait for
  the first idle opportunity instead of replacing live provider state.
- Removed the arbitrary 32-item workspace agenda limit.

## Provider and tool reliability

- Retry `response.incomplete` provider events with their structured reason
  instead of aborting the logical turn with an opaque error.
- Added a conservative line-aware `fs.edit` fallback for unique indentation and
  line-ending drift while preserving exact-first replacement.

## Terminal input

- Restored Shift-Enter and Ctrl-Enter newline insertion through Kitty CSI-u and
  xterm keyboard reporting without losing plain Escape cancellation.
- Preserve multiline Ctrl-V paste as one bounded paste event when a terminal
  fails to emit bracketed-paste markers.
