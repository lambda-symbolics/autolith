# Autolith 0.32.0

Autolith 0.32.0 makes installed upgrades explicit, bounds durable conversation replay, and removes obsolete interfaces and migration machinery.

- Add canonical `(update)` operation with fresh selected-release checks and clear source and Nix guidance.
- Store durable conversations in deterministic per-conversation chunk logs, rotate logs at compaction, resume from the newest chunk, retain one previous normal transcript as fallback, and replay recovery only for the active conversation.
- Bound resumed transcript display to 250 entries by default while preserving complete durable logs.
- Batch raw single-line terminal paste bursts into one insert event without changing multiline or control-key semantics.
- Consolidate workspace file access on `resource.read` and revision-gated `resource.edit`, removing the redundant `fs.read` and `fs.edit` tools.
- Make 0.31.1 the final bridge for legacy `overlays/*.lisp` mutations. Selected historical private commits still replay and normalize, but installations with loose overlay files must import them through 0.31.1 before upgrading.
- Preserve mutation failure journaling when conditions are not readable Lisp objects.
- Remove the obsolete technical specification, dependency-shape tests, legacy overlay subsystem, and duplicated resource observation and digest machinery. The reduction pass removes 3,474 net tracked lines, including 930 source lines and 592 test lines.
- Replace the repository landing page with a concise demo-led guide to prose, callable Lisp operations, workers, self-inspection, recovery, and contribution documentation.
