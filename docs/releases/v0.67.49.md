# 0.67.49

## Client exit

- Restore the normal terminal screen when closing a client, including `(close)` and `(exit)`.
- Restore terminal input modes after failed screen cleanup, undo interrupted screen entry, and retry interrupted screen exit.
- Print the command to reopen the client's last channel after restoring the terminal, including after channel switches, detach, and disconnect.
- Use one client finalization path for terminal cleanup and exit reporting.

## Channels and sidebar

- Show the inbox as `home ~`, with other channels indented beneath it. Store that parent relationship while preserving existing nested channels and agent ancestry.
- Put `(new)` and `(delete)` on one fixed row, with distinct action colors and working individual click targets.
- Limit sidebar controls and width reservation to fullscreen mode. Ctrl-S no longer shrinks the prompt in streamed mode.
- Keep home's direct children eligible for recent-channel selection, and sort newly hosted channels by creation time before their first saved history.

## Compaction and project links
