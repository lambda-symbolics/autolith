# Autolith 0.71.0

## Child agents

You can now ask Autolith to change the model, reasoning effort, or permissions of an existing child agent.

The separate tool-grant configuration for child agents has been removed.

## Reliability

- Windows restarts no longer allow a competing process to open the same world during the handoff.
- Failures during channel startup and request handling are reported without stopping other channels.
- Your terminal connection is preserved while a failed listener is replaced.
- A deadlock during channel checkpointing has been fixed.
- Failures while resuming a channel are contained within that channel.
- Jobs interrupted by Lisp deadlines now complete cleanup.

## Memory use

- The active Lisp heap limit is now 4 GiB.
- Less memory is used during scans of long conversations and large job histories.
- Frequent world activity updates no longer cause an unbounded backlog of pending refreshes.

Update with `(update)`.
