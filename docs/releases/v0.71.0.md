# Autolith 0.71.0

## Child agents

- Use `(child.update :child "helper" :compact t)` in place of `child.compact`.
- Change an idle child's model, reasoning effort, or permission mode with `child.update`.
- Children use the tools configured for their agent. Per-child tool grants have been removed.

## World stability

- Fix a Windows restart race between publishing the handoff marker and releasing writer leases.
- Contain serious conditions at saved-core debugger and shared-world request boundaries.
- Retry transient accept failures and replace failed world and channel listeners without dropping accepted clients.
- Preserve native deadline propagation after inline job settlement.
- Fix channel quiescing, checkpoint cleanup, and resume failure handling.

## Memory use

- Raise the active SBCL heap limit to 4 GiB.
- Stream durable job records before retaining summaries.
- Bound retained conversation history during scans.
- Reuse validated mutation journal prefixes.
- Bound pending world activity refreshes.

Update with `(update)`.
