# Autolith 0.17.0

Autolith 0.17.0 adds Grok subscription access alongside ChatGPT, serving
grok-4.5 through the user's xAI account without bundling or launching
Grok Build.

## Grok subscription access

- Added the grok-4.5 model with its 500,000 token context window to the
  `(model)` picker. The configured model now selects the serving provider,
  and switching between the GPT and Grok families replaces the provider
  in place.
- Spoke the Grok CLI chat proxy's standard streaming Responses dialect,
  including the proxy's client version gate and encrypted reasoning
  replay.
- Flattened Autolith's namespaced tools into dotted wire names on the way
  out and split completed calls back on the way in, so conversations
  persist in one provider-independent shape and can move between the GPT
  and Grok families.
- Clamped Autolith's wider reasoning effort scale onto Grok's low,
  medium, and high efforts.

## Grok authentication

- Added `autolith --auth grok`, and made plain `autolith --auth` follow
  the configured model's provider family. In a session, `(auth)`
  authenticates the active provider.
- Implemented the RFC 8628 device authorization grant against the xAI
  issuer, with rotating refresh tokens stored only in Autolith's private
  credential store.
- Imported one bounded access token from an existing Grok Build
  `auth.json` when no Autolith credentials exist yet, without ever
  spending that installation's rotating refresh token.
- Named the right login command in every Grok credential failure.
