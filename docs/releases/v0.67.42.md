# 0.67.42

## Headless jobs

- Run an inline assignment with `run-job --prompt TEXT`, or use `--prompt -` to read it from standard input instead of supplying a job envelope through `--input`.
- Select `--role`, `--timeout-seconds` and `--id`. Inline jobs default to the `task` role, an 86,400-second timeout, a generated ID and a permissive object output contract.
- Reuse role validation, telemetry, live events and atomic result publication. Publish normal failure artifacts and terminal events for failed or oversized prompt reads; omit the empty input section from inline assignments.
- Bound stalled standard-input prompt reads by the requested timeout and publish a timed-out result with terminal events. Preserve explicitly supplied `:input nil` in file-envelope assignments.
- Return failed headless-job exit statuses directly from both launchers, without entering interactive crash recovery.
- Forward the new value-taking options through both launchers.

## Model limits

- Set a durable `:max-output-tokens` cap for ordinary model requests, with an `AUTOLITH_MAX_OUTPUT_TOKENS` environment override. Leave it unset for the provider default.
- Apply the configured fallback during compaction projection and reserve the full generation cap during context admission.

## Custom providers

- Register an OpenAI-compatible provider with `:api-key-environment-variable` to prefer an environment key over the private credential store, with stored-key fallback when the variable is unset or empty.
- Use the same credential source for requests and model discovery. Preserve the variable name during provider reconfiguration without retaining its secret value; reject empty variable names.

Update with `(update)`.
