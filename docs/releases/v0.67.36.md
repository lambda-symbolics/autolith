# 0.67.36

## Scheduling and context

- Defer ordinary goal wakeups when matching scheduled or admitted mission work is pending.
- Give child agents access to their own durable overflow contexts, with bounded atomic metadata publication.
- Preserve measured context usage when routing providers add or rewrite request fields.

## Startup and tools

- Preserve caller ASDF settings for subprocesses while isolating private runtime startup. Send source bootstrap diagnostics to stderr.
- Report terminal program status only for the root agent, and report blocked permission before pausing input.
- Accept underscore-spelled tool argument names when the schema declares hyphenated names, including nested objects and array items. Prefer the declared spelling when both are supplied.
