# Autolith 0.28.0

Autolith 0.28.0 adds first-class Anthropic Messages API support and tightens editing, provider, and conversation boundaries.

- Add a built-in pay-per-token Anthropic provider for Claude Opus 5, Claude Sonnet 5, and Claude Haiku 4.5 through the streaming Messages API.
- Translate portable text, refusal, URL and base64 image, tool-use, and tool-result content into Anthropic messages while preserving ordering and tool-call linkage.
- Validate Anthropic stream lifecycle, usage, identifiers, and malformed content as structured provider failures, including common request identifiers from HTTP and stream errors.
- Load Anthropic credentials from `ANTHROPIC_API_KEY` or validate and store an API key through `(auth "anthropic")`.
- Fix the `/auth` optional provider declaration that could signal an unknown type specifier instead of starting authentication.
- Warn after Common Lisp, Scheme, or Clojure writes and edits whose delimiters appear unbalanced.
- Correct `resource.edit` union schemas so every editing variant declares its object type.
- Replace repeated user-input and persisted-conversation dispatch with focused CLOS protocols, and make task admission/cancellation race coverage deterministic.
