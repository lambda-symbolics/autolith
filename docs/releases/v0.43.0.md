# Autolith 0.43.0

Autolith 0.43.0 adds live failure diagnosis and executable recovery proposals while tightening shared runtime infrastructure.

- Adds `Ask Autolith why this failed` to the live restart debugger. Diagnosis runs independently without unwinding the signaling stack, shows its explanation beside the still-live restarts, and can propose up to three validated recoveries that invoke a restart, prepare a repair, retry, return replacement values, or abort.
- Makes automatic permission selection session-wide, removes the deferred scheduler, and gives tool failures machine-readable codes.
- Keeps oversized tool results readable through context resources, carries namespace descriptions through the tool registry, and registers user source trees for the REPL.
- Extracts device authentication, transcript items, image control, provider streaming, and shared file-locking behavior into focused reusable libraries and packages them through Nix.
- Validates durable records declaratively, resets inherited lock state after forks, and reflows live terminal content after relayed resizes.
