# Autolith 0.67.66

- Fullscreen startup shows the mascot while the world server preloads home. The Autolith banner then appears centered in the transcript pane, with no channel selected until you choose one in the sidebar.
- Run `autolith open` to open the most recently touched top-level channel in the current workspace, or start one if there is none. Pass a channel ID to open it directly.
- Match abbreviated paths with `@` completion, and add skill directories through settings or `init.lisp`.
- Connect to MCP 2026-07-28 and legacy servers. Refresh the tool catalog when a server reports a change.
- Use clifff for structured content search and cl-worktree for Git repository identity.
- Reduce idle channel CPU use and give the active SBCL process a 3 GiB heap.

Update with `(update)`.
