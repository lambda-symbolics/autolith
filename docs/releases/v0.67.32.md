# 0.67.32

## Context accounting

- Resume conversations with the last verified provider-input measurement instead of losing the measurement at process startup. Persist counters and request fingerprints without storing provider objects or prompt bodies in the accounting record.
- Revalidate the provider, policy, headers, history and final request before using a saved measurement. Recompute after incompatible changes and use conservative estimates when no verified measurement is available.
- Calculate the modeline meter and compaction threshold from the current growing context estimate. Count cached input fully toward the context window.

## Terminal

- Open Markdown link destinations from their rendered labels, including links in headings, wrapped text and streamed responses. Preserve link actions when applying heading styles and show readable labels in plain output.
- Press Ctrl-Z to invoke the existing `(detach)` flow from an idle prompt or an active turn.

## Memory and identifiers

- Show the IDs of delivered memories in relevant-memory notices. Use those references with `(memory "ID")` or `memory:id/ID` to inspect the recalled evidence.
- Allocate native idsmall identities for new memories. Resolve legacy UUID memories through stable short aliases without rewriting their stored identity, and provide distinguishing references when a lookup is ambiguous.
- Use short identifiers for new user-addressable agenda items, papercuts, generations, mutation records, task runs and scheduler executions.
- Resolve exact stored identifiers before unambiguous legacy prefixes for agenda items, papercuts, generations and mutations. Check persisted records, closed reports and pending checkpoint directories before allocating replacements, including agenda transport collisions.
- Open recalled memories in the memory manager using their displayed native or legacy reference.

## Providers

## Editor integration

- Handle editor disconnection during streamed ACP updates and pending-thought flushes without failing the active response.
