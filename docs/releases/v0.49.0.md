# Autolith 0.49.0

Autolith 0.49.0 adds standalone page retrieval and per-call RLM model selection.

- Retrieve a known HTML or Markdown page with `web.gist`, including when provider web search is disabled or handled remotely. Supply an absolute HTTP or HTTPS URL. Thanks to [Lenny99's contribution](https://github.com/lambda-symbolics/autolith/pull/60).
- Select `model` and `effort` for `rlm.infer`, `rlm.map`, or `rlm.complete`. Use one selection for the whole subtree, including mapped frames and nested inferences.
- Reconstruct private image commits containing multiline mutation metadata without interpreting that metadata as Lisp code.
- Prefer direct descriptions of the user's actions in instructions, rather than attributing those actions to interface elements.

Update with `(update)`.
