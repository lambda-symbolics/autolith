# Autolith 0.20.0

Autolith 0.20.0 makes resume and session recovery much faster and more reliable,
adds Codex-style plan tools, and hardens Grok and rate-limit handling.

## Resume picker and session recovery

- Cached compact resume-picker metadata so `(resume)` no longer fully scans every
  conversation log for tallies and previews.
- Persisted unprocessed follow-ups and steering across process restart for the
  same conversation.
- Deferred remaining queued follow-ups after HTTP 429 instead of immediately
  submitting the next one.

## Plan tools and Grok reliability

- Added workspace `plan.list`, `plan.update`, and `plan.clear` tools for ordered
  plan points with `pending`, `doing`, and `done` status.
- Filtered foreign encrypted reasoning when switching between Codex and Grok
  families.
- Surfaced streamed provider error bodies and omitted invalid empty tool choices
  on Grok compaction requests.
- Clarified that `fs.edit` requires exact file indentation and must not copy
  `fs.read` line numbers.

## Releases

- Publish GitHub release metadata as soon as a version tag validates, without
  waiting for the Linux binary release service.
- Added a backfill workflow for missing GitHub releases on existing tags.
