# Autolith 0.67.61

## Channels and CLI

- Create an unattached channel with `autolith new [DIRECTORY]`, then attach with the printed `autolith open ID` command.
- Create channels faster on a running world server by skipping unnecessary context fingerprinting.
- Send Lisp forms and commands with `autolith tell` without opening interactive pickers. Plain text still goes to the channel as a message.

## Terminal client

- Load older transcript history from disk as you scroll up.
- Use Ctrl+Page Up and Ctrl+Page Down to jump between user and agent messages, placing the target just above the modeline when possible.
- Replay cache notices where they originally appeared in the transcript.

Update with `(update)`.
