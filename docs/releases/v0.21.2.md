# Autolith 0.21.2

Autolith 0.21.2 improves the interactive programming workflow and fixes live
input wrapping.

## Terminal input

- Typed user input now wraps at word boundaries instead of splitting words at
  the terminal edge.
- Cursor placement, vertical movement, suggestions, completion footers, and
  terminal resizing follow the same word-aware layout.

## Lisp scratchpads

- New session-scoped Lisp scratchpad tools list, read, write, edit, run, and
  delete files in a per-conversation cache folder.
- Scratchpads support iterative experiments without adding transient source to
  the workspace.

## Live model controls

- `(model)` and `(effort)` now execute during an active turn instead of waiting
  for the turn to finish.
- A newly selected model is installed before its effort picker opens, so the
  available effort levels immediately match that model.
