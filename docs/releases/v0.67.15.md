# Autolith 0.67.15

## Improvements

- Request an hour-long prompt cache on Anthropic and OpenRouter Claude with `(settings :prompt-cache-ttl "1h")`. Use the requested lifetime to schedule precompaction and idle compaction, unless an explicit retention estimate overrides it.
- Preserve warm request prefixes on resume and replay recorded precompaction at its original position. Bound oversized old tool outputs after estimated cache expiry, with excerpts and references to the full evidence.
- Share reusable request items and inference-frame views. Include final wire fields and cache-marker placement in cache-miss diagnostics, and send the conversation cache key as the OpenRouter session identifier.

## Fixes

- Preserve the complete ordered native compaction window, including reasoning and multiple opaque checkpoints, through publication and reload.
- Require a completed, bounded, structured portable handoff before publishing a checkpoint. Record completed compaction attempts before validation, including rejected responses and unknown usage.
- Validate the next encoded request before checkpoint publication, including tool schemas, restricted-round tool choice, temporary context and the selected output allowance.
- Retain recent user turns verbatim during portable compaction, summarize displaced evidence, preserve failed attempts and uncertain external effects, and rebuild current plan and mission context from authoritative stores.
- Preserve arrivals and unfinished work during compaction, with transactional rejection and repeated continuation accounting.
