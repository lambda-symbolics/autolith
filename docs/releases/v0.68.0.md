# Autolith 0.68.0

## Conversation storage

- Fix conversation-store corruption when an ACP client lists conversations during an active tool call, with or without a directory filter.

## Providers and compaction

- Add `:request-headers` to `register-openai-compatible-provider`. Supply a function of the conversation to compute headers for each completion request.
- Use the durable conversation identifier for headers such as `X-Session-Id` to keep cache routing stable across requests and resume. Request headers override static headers without replacing bearer authentication.
- Estimate proactive compaction from the prepared provider request, including selected tools, context and the output limit.
- Prepare cold conversation history before estimating its request size.
- Preserve child notes when request estimation triggers compaction. Acknowledge their delivery only after a successful provider request.

## Agents and knowledge

- Remove agent roles, role presets and role selection from child agents, configuration, commands and tools. Give each child its assignment directly.
- Activate valid rules and learned procedures automatically. Remove the separate admission commands and approval step.
- Remove `(complain)` and its `(wtf)` alias, including correction generation, interactive review and their dedicated tests.

## Long-running work and startup

- Remove execution deadlines from shell commands, repository searches, Git operations and headless jobs.
- Remove fixed deadlines from client replies, endpoint discovery, owner queries, catalog requests and saved-edit diagnostics.
- Wait for channel and world startup while their processes are alive, and allow checkpoint reconnection until cancellation.
- Remove fixed deadlines from telemetry uploads and final draining.
- Fix evaluation-endpoint client shutdown through the updated Clifff dependency.

Update with `(update)`.
