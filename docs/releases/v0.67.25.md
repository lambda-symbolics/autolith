# Autolith 0.67.25

## Changes

- Configure automatic lightweight goal continuations with `(settings :goal-continuation-limit 16)` or `:unlimited`. The durable setting defaults to eight turns between user messages.
- Use display names or canonical dispatch names in tool contracts and diagnostic probes. Canonical names take precedence; display aliases must identify one tool.
- Rank diagnostic probes with partial hypothesis predictions. A prediction from only one hypothesis receives a lower ranking weight than two different predictions.

## Fixes

- Run queued commands and Lisp forms between goal turns. Resume a goal after queued input only when its loop yielded to that input, and allow ordinary job-completion wakeups after a lightweight goal completes.
- Announce failed scheduled occurrences once and retain pending execution exits. Recheck scheduled notices before appending them.
- Recover unavailable saved providers and incompatible saved model/provider pairs after user initialization, with a startup notice. Invalid explicit selections report an error.
- Skip startup update choices without an interactive terminal.
- Settle a first local context-admission refusal with known zero usage, releasing its mission reservation without refunding the turn. Failures after an admitted provider request retain unknown-usage accounting.
- Apply the same resolved tool contracts during diagnostic selection, precondition checks, execution and observation reporting. Reject ambiguous display aliases and skip unavailable probes without consuming the execution budget.

Update with `(update)`.
