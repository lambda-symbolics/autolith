# Autolith 0.67.21

## Improvements

- Survey failed tool calls with `autolith tool-failures`, grouped by tool and error shape with example arguments.
- Accept relative resource paths and late line windows, and clamp oversized shell-log reads to the supported limit.
- Find jobs by execution ID, explain missed lookups, and accept task batches with no shared context.

## Fixes

- Preserve observed lines across resource edits and search valid constraint locations when another location is missing.
- Trim long agenda text at word boundaries, document text limits, and tolerate irrelevant query or window arguments on resource views.
- Suppress stale telemetry reports.
- Use canonical Lisp command forms throughout the guide, command help, and historical release notes; reserve slash examples for syntax and parser documentation.

Update with `(update)`.
