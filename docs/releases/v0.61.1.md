# Autolith 0.61.1

## Fixes

- Keep completed assistant answers in fullscreen history when a turn finishes while detached. Late localgroup attachment now shows the final answer and any permission question, including after detaching mid-stream. Fixes #92.
- Prevent OpenBSD release runtimes from crashing on CPUs with indirect-branch tracking by applying the linker opt-out used by OpenBSD's SBCL port. Thanks to Roerick Sweeney for the fix.
- Upgrade preinstalled NetBSD release dependencies during packaging, including PCRE2, and support rebuilding an existing NetBSD release through GitHub Actions.

## ACP and editor integration

- Discover typed session state, settings, model catalogs, and native operations through `_autolith/` protocol methods. Invoke native tools and commands with their argument decoding and editor approvals.
- Steer an active turn or queue a durable follow-up from an editor, including while approval is pending. Accepted input survives session close and reload.
- Page durable conversations and read bounded workspace resources or session-owned shell logs.
- Inspect, steer, and cancel owned jobs; read child transcripts as text or structured ACP updates. Detached job completions can continue the primary session and stream updates to the editor.
- Improve conversation replay, tool-result delivery, reasoning separation, cancellation, and reader shutdown.

Update with `(update)`.
