# Autolith 0.69.1

## macOS

- Fix starting the arm64 release from an application running under Rosetta, including AUI's **Try again** after stopping the server in Terminal.
- Select the native arm64 release when installing from a Rosetta shell on Apple silicon.

## Channels

- Use `(exit)` to disconnect your client and leave the channel and its work running. This replaces `(detach)` and the old channel-stopping behavior of `(exit)`.

## Release builds

- Fix native search validation in musl release builds.

Update with `(update)`.
