# 0.67.50

## Startup and channel status

- Keep terminal input on the startup thread during the first client attachment. Start the responsive reader when boot finishes.
- Report the attached terminal client's PID in channel status, with observer PIDs listed separately.
- Complete terminal takeovers without recursively acquiring the daemon runtime lock.

## Reusable shell sessions

- On Linux and macOS, use `shell.run` with a named `session` to retain Bash variables, functions, environment and working directory between commands, including Nix development environments.
- Inspect, reset and close sessions with `shell.sessions`, `shell.reset` and `shell.close`.
- Serialize commands per session, retain bounded output logs, and stop the session on timeout or cancellation.

## Lisp source expansion

- Click a collapsed Lisp form's text or ellipsis to expand its complete input, including after asynchronous handoff, completion and history replay.
- Format compact Lisp source for the available width without reading or evaluating it. Preserve existing multiline formatting.

Update with `(update)`.
