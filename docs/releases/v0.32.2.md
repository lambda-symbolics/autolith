# Autolith 0.32.2

Autolith 0.32.2 improves prompt routing, live-image reliability, provider model selection, and Fireworks compatibility.

- Unify terminal prose and callable `PROMPT` through one canonical primary and child path, including image attachments, exact-once child response promotion, and race-safe recalled input ordering.
- Detach cancelled Lisp workers promptly and repair active self-mutation checks across fresh worker processes.
- Preserve typed checkpoint preparation failures instead of replacing them with generic errors.
- Limit `(model)` and `(models)` to models from the configured provider.
- Allow Responses providers to omit the reasoning request object when their serving stack does not support it.
- Register Fireworks Qwen 3.7 Plus with its 262k context window and omit the unsupported reasoning parameter for that model.
- Direct macOS installer users to the supported Nix installation path.
- Refresh the repository landing page and contributor guidance.
