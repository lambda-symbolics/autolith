# Autolith 0.67.16

## Improvements

- Start inference frames in the background, inspect their progress, and collect or cancel them by handle. Wait for several frames without serial blocking.
- Choose a child frame's model within the root provider and reduce its reasoning effort while sharing the root budget.
- View model-request spending in `/status`. Use provider-reported charges or model price estimates, distinguish unpriced requests, and set a process spending limit with `(settings :cost-limit 5)`.

## Fixes

- Validate child model overrides against the root provider and the inherited reasoning effort.
- Record cancelled frame outcomes and invoke completion callbacks exactly once, including queued cancellation and startup races.

Update with `(update)`.
