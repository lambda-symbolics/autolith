# 0.67.45

## Agent names

- Start agents with their short channel ID, then infer a descriptive name alongside the automatic conversation title.
- Preserve names chosen explicitly or supplied by a parent. Resolve generated-name collisions with numbered suffixes.

## Channels and local control

- Select channels by agent name, `@name`, participant ID, channel ID, or a unique ID fragment with `open` and localgroup's `tell`, `detach`, `pause`, and `kill`.
- Use `autolith lg tell NAME "message"` to message a cold channel and start its resident agent without attaching a terminal. Direct messages and mentions from other channels also wake cold recipients.
- Remove `autolith open ID --detached`. Use `autolith open ID` to attach, or `autolith --detached` to start a new unattended channel.
- Remove `autolith lg attach`. Use `autolith open TARGET --read-only` to observe a channel without taking control; read-only mode applies when switching channels too.

## Tool display

- Show admitted shell commands in the live command list while queued, including when another job occupies the worker.
- Attach background-completion notices to their original tool call even after its earlier display event leaves the recent-event cache.
- Click a `lisp.eval` input block in fullscreen to expand its complete syntax-highlighted Lisp source. Click again to collapse it; resizing and tool completion preserve the selected view.
- Color matching parentheses by nesting depth in Lisp tool inputs, returned source, and values, including local Lisp evaluation. Keep operator highlighting separate from adjacent parentheses.

## Version reporting

- Identify the running world server's version in the startup banner and update notice.
- Report client/server version mismatches as informational notes in the initially opened channel, with both versions.

Update with `(update)`.
