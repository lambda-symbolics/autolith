# 0.67.39

## Channels

- Send to the current channel with `(channel.send :text CONTENT)`; add `:channel "@name"` to address another agent. This replaces `(prompt)`.
- Attach images with `:images #("/path/image.png")`; copy attachments into durable storage for queued delivery and active-turn steering.
- Use computed text and `(read-file "request.org")` through the same tool-backed interface.
- Send explicit local calls as the user and model calls as the requesting participant.

## Fullscreen

- Span the transcript pane with the context-compaction divider and reflow it when the width changes.

## Runtime

- Remove obsolete foreground process-replacement handoffs; use supervised session and terminal-controller paths for detached operation.
- Restore bounded successful resource reads instead of refusing oversized requested windows.

Update with `(update)`.
