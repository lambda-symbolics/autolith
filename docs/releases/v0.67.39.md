# 0.67.39

## Channels

Use `(channel.send :text CONTENT)` to send to the current channel, or add `:channel "@name"` to address another agent. Attach images with `:images #("/path/image.png")`. Computed text and `(read-file "request.org")` work through the same tool-backed interface. This replaces `(prompt)`.

Image attachments are copied into durable storage for queued delivery and active-turn steering. Explicit local calls send as the user; model calls send as the requesting participant.

## Fullscreen

The context-compaction divider spans the transcript pane and reflows when its width changes.

## Runtime

Remove obsolete foreground process-replacement handoffs. Use the supervised session and terminal-controller paths for detached operation.

Restore bounded successful resource reads instead of refusing oversized requested windows.
