# Autolith 0.23.0

Autolith 0.23.0 expands terminal workflow control, response guidance, and
portable source development.

- Recall the newest queued follow-up with empty Tab, then use Shift-Tab to cycle
  backward through queued messages and commands while preserving FIFO position,
  edits, images, persistence, and active-turn semantics.
- Add opt-in Simple Technical English guidance, enabled with `(ste t)` and
  disabled with `(ste nil)`, with durable global preferences and per-request
  prompt integration.
- Accept supported release SBCL runtimes at or above the tracked minimum and use
  hash-verified matching runtime sources for portable macOS arm64 development.
- Harden UTF-8 reads, MCP worker fixture execution, release fixture isolation,
  and scripted terminal-size tests.
