# Autolith 0.67.59

## Transcript history

- Fix long conversations becoming unresponsive when opening a terminal view or loading older transcript history. Autolith reads the segments needed for the page instead of scanning the entire conversation.

## MCP tools

- Use `mcp.search` to find and activate MCP tools by name or description. Model requests include schemas only for active MCP tools.
- Limit the number and total schema size of active MCP tools. New activations can evict the oldest ones, and refreshing a server preserves activated tools that are still available.

Update with `(update)`.
