# Autolith 0.72.0

- The boot screen shows the Autolith and running SBCL versions and reports actual startup progress. By default, both `autolith` and `autolith open` wait for Space when ready. Set `(settings :boot-screen-linger-p nil)` to continue immediately.
- `child.spawn` creates a channel, subscribes its parent to idle notifications, and sends the first turn through ordinary channel delivery.
- Background tool jobs notify their owning channel at any depth. `job.wait` has been removed. Use the completion preview, or inspect the result with `job.get`.
- Ctrl-C now detaches the terminal like Ctrl-Z, leaving the channel running. Slow terminal clients stay attached, and subscribers are notified when an agent becomes idle.
- Delete saved channels directly from the `(open)` picker. The `(fork)`, `(refine)`, and `(what-changed)` commands have been removed.
- Unix package updates keep the three most recent release installations. Packaged builds bundle SBCL 2.6.10. Source builds require SBCL 2.6.4 or newer.
- A fatal startup failure exits rather than opening recovery automatically. To enter recovery, run `autolith --recovery`.

Update with `(update)`.
